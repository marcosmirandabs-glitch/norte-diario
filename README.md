# Norte Diário

Uma frase por dia, um passo de cada vez. Página única (HTML), sem servidor, instalável no celular (PWA).

Arquivos: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`.

## Publicar no GitHub Pages (grátis)
1. No GitHub: **New repository** → nome `norte-diario` → Public → Create.
2. **Add file → Upload files**, arraste todos os arquivos desta pasta → Commit.
3. **Settings → Pages → Branch: main / (root) → Save**.
4. Em ~1 minuto o link fica em `https://SEU-USUARIO.github.io/norte-diario/`.

## Instalar no celular
- Android (Chrome): menu ⋮ → *Instalar app* / *Adicionar à tela inicial*.
- iPhone (Safari): Compartilhar → *Adicionar à Tela de Início*.

Os dados (anotações, metas) ficam no aparelho/navegador de cada pessoa. Use *Backup (.json)* para levar para outro dispositivo.
